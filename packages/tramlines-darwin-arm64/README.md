# @six5536/tramlines-darwin-arm64

Prebuilt `tramlines` binary for **darwin-arm64** (macOS, Apple silicon). This is an
internal artifact of `@six5536/tramlines`, which
installs it automatically as an optional dependency on a matching machine. Don't
depend on it directly; install `@six5536/tramlines` instead.
