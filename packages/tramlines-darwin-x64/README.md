# @six5536/tramlines-darwin-x64

Prebuilt `tramlines` binary for **darwin-x64** (macOS, Intel). This is an internal
artifact of `@six5536/tramlines`, which installs it
automatically as an optional dependency on a matching machine. Don't depend on
it directly; install `@six5536/tramlines` instead.

## Status

**Unstable.** `tramlines` is at a 0.x version, and its commands, options and file formats can change in any release.
