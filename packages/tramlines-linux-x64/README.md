# @six5536/tramlines-linux-x64

Prebuilt `tramlines` binary for **linux-x64**. This is an internal artifact of
`@six5536/tramlines`, which installs it
automatically as an optional dependency on a matching machine. Don't depend on
it directly; install `@six5536/tramlines` instead.
